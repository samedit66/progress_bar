# `progress_bar`

### Portable terminal progress bars for Eiffel

</div>

`progress_bar` is a void-safe Eiffel library for manually updated and
iterable terminal progress bars. Its public classes use the `PB_` prefix and
are designed to compile with both EiffelStudio and Gobo Eiffel.

The public API and documentation are under active construction.
